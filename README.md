# 📜 Projeto Cordel

Site desenvolvido como homenagem à literatura de cordel, utilizando o poema **"Tecnologia Moderna"** de Milton Duarte. O projeto combina a riqueza da cultura popular nordestina com recursos modernos de CSS como o efeito parallax.

## 📋 Sobre o Projeto

Este projeto foi desenvolvido durante o curso de **HTML5 e CSS3** do professor Gustavo Guanabara. O site apresenta o poema de cordel de Milton Duarte com um visual temático e estilizado.

**O que foi praticado:**
- Efeito **parallax** com CSS puro
- Uso de imagens de fundo e sobreposição de texto
- Tipografia criativa e temática
- Estruturação semântica com HTML5
